# Стиль на время чата

Сюда Claude в начале каждого чата скачивает стиль человека с его страницы «Монтажный стол» (`scripts/brand_sync.py pull`) и записывает правки обратно (`brand_sync.py push`). Сам стиль хранится на странице, в репозиторий он не попадает.
Пример заполненного стиля: `examples/vladimiruss/`.
