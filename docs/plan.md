# plan.json: что и когда показать

Claude правит только этот файл. Все времена здесь — **секунды исходной записи** (как в `words.json`). `scripts/timeline.py` переводит их во время готового ролика. Поэтому, если человек вырежет или вернёт строку, графика сама встанет на свои слова.

Чтобы найти время слова, смотри `words.json`: каждое слово записано как `["слово", секунда]`. Удобно ставить карточку на начало слова минус 0.05 с.

```json
{
  "title": "ChatGPT ведёт на тебя досье",
  "hook": {"lines": ["ChatGPT ВЕДЁТ", "НА ТЕБЯ *ДОСЬЕ* 👀"], "until": 3.1},
  "cards": [
    {"type": "list", "src": [2.0, 5.3], "title": "ДОСЬЕ НА ТЕБЯ", "items": ["Привычки", "Работа", "Деньги"], "at": [2.84, 3.6, 4.16]},
    {"type": "text", "src": [5.6, 7.2], "title": "Кое-что он\n*додумал* сам", "sub": "и ты этого не говорил"},
    {"type": "number", "src": [15.5, 18.0], "value": "291", "label": "записей обо мне"},
    {"type": "image", "src": [20.0, 22.5], "file": "src/result.png", "label": "РЕЗУЛЬТАТ"},
    {"type": "cta", "src": [50.4, 53.4], "word": "ДОСЬЕ", "label": "Комментарий",
     "alts": [{"type": "word", "text": "ДОСЬЕ", "fx": "slam", "label": "Слово крупно"},
              {"type": "note", "text": "напиши ДОСЬЕ — пришлю чек-лист", "label": "Заметка"}]}
  ],
  "split": [[10.0, 44.1]],
  "shots": [
    {"rec": "rec1", "m": [[10.0, 0.0], [14.9, 1.3]], "crop": [[0, 1250]]},
    {"rec": "rec1", "m": [[14.9, 2.4], [15.6, 29.8]], "crop": [[0, 300]], "ff": 1},
    {"rec": "rec1", "m": [[15.6, 30.0], [20.3, 50.5]], "crop": [[0, 420]], "blur": [[29, 52, 140, 430, 1030, 1450]]},
    {"img": "src/result.png", "src": [28.5, 34.0], "label": "РЕЗУЛЬТАТ"},
    {"id": "s1", "src": [34.0, 44.1], "label": "Чек-лист",
     "scene": {"title": "*Шаг 3* Удали лишнее", "tag": "2 минуты", "tag_at": 35.2, "foot": "Настройки → Персонализация",
               "body": [{"type": "checklist", "items": ["Память", "Архив", "История"], "at": [36.0, 38.1, 40.4]}]},
     "alts": [{"label": "Полоски", "scene": {"title": "*Шаг 3* Удали лишнее", "body": [{"type": "bars", "items": [["Память", 80], ["Архив", 45]], "at": [36.0, 38.1]}]}}]}
  ],
  "taps": [[14.8, "rec1", 1041, 1917]],
  "hl": [[11.9, 14.8, "rec1", [30, 1570, 1070, 270], "ПРОМПТ"]],
  "steps": [[10.0, "ШАГ 1", "Покажи досье"], [20.3, "ШАГ 2", "Что он додумал"]],
  "zoom": "auto",
  "fix": {"57": "чек-лист"},
  "accent": [12, 13],
  "no_accent": []
```

## Поля

- **title** — название ролика на странице проверки.
- **hook** — плашка-хук в начале.
  - `lines` — 2–3 строки, до ~14 знаков в строке. `*слово*` выделяется цветом акцента.
  - `until` — до какой секунды исходника держится хук. Если раньше начинается сплит, хук уходит вместе с ним.
- **cards** — карточки поверх человека (на полном экране, не в сплите). У каждой есть `src: [начало, конец]`. Необязательные поля:
  - `label` — короткое имя варианта для «Монтажного стола» («Чек-лист», «Слово крупно»);
  - `alts` — другие варианты этого же момента: `[{"type": …, поля…, "label": …}]`. Человек выбирает вариант на странице и сразу видит его в живом черновике. `id`, `src`, `x`, `y`, `in_split` берутся у основного;
  - `y` — центр по вертикали, по умолчанию карточка висит от `brand.cards.top`;
  - `x` — центр по горизонтали;
  - `in_split: true` — показывать и во время сплита.
  - `keep: true` — показывать, даже если все слова под карточкой вырезаны (например, карточка на вставленной паузе). Без него такая карточка пропадает.

  | type | поля |
  |---|---|
  | `text` | `title` (строка, `\n` — перенос, `*акцент*`), `sub` — мелкая подпись, `size` — кегль заголовка (76) |
  | `list` | `title`, `items` (до 5), `at` — секунды, когда появляется каждый пункт, `icon`: `check` или `num` |
  | `number` | `value` (`"291"`, `"0%"`, `"x3"` — число досчитает от `from`), `label`, `color` |
  | `image` | `file` — путь к картинке в папке ролика (`"src/pic.png"`), `label` — плашка, `size: "full"` — на весь экран, `w`/`h` — предельный размер карточки |
  | `sticker` | `emoji`, `size` (220), `rot` (−8°), `x`, `y` |
  | `cta` | `word` (по умолчанию `brand.cta.word`), `hint`, `type_at` — когда начинает печататься |
  | `follow` | `tap` — секунда нажатия на кнопку |

  Времена внутри карточки (`at` — одно число или список, `tap`, любое поле на `_at`) тоже секунды исходника: `timeline.py` переводит их сам.

### Библиотека анимаций

Каждую можно поставить карточкой поверх человека или частью моушн-панели в сплите (`scene.body`). Ширина ~860 px, высоту шаблон считает сам.

| type | что это | поля |
|---|---|---|
| `chat` | вопрос печатается, Claude «пишет» и отвечает | `q`, `a`, `who_q` («Ты»), `who_a` («Claude»), `at: [вопрос, ответ]` |
| `search` | строка поиска, счётчик источников, результаты | `q`, `status`, `count`, `rows: [[заголовок, подпись]]`, `at: [запрос, счётчик, строка1, …]` |
| `checklist` | пункты отмечаются галочкой по словам | `title`, `items`, `at` |
| `bars` | полоски-цели растут до значения | `title`, `items: [[подпись, число]]`, `max`, `unit`, `hot` (номер красной), `stuck` (дрожит), `at` |
| `funnel` | воронка и плашка «здесь уходят» | `items: [[этап, число]]`, `drop`, `drop_at`, `at` |
| `calendar` | месяц, дни отмечаются штампами | `title`, `days`, `start` (1 = пн), `marks: [[день, "подпись" или ""]]`, `at` |
| `profile` | аватар, ник, счётчик подписчиков | `handle`, `name`, `followers: [с, до]`, `label`, `img`, `count_at` |
| `flip` | перекидные цифры | `value` («05», «1500»), `from`, `label`, `at: [старт]` |
| `polaroids` | 1–4 фото полароидами | `files`, `captions`, `at` |
| `phone` | телефон с картинкой или кадром | `file`, `label`, `rot` |
| `note` | стикер-заметка, текст пишется от руки | `text`, `color`, `rot` (шрифт `brand.fonts.notes`, по умолчанию Caveat) |
| `beforeafter` | ДО / ПОСЛЕ, «после» открывается шторкой | `before: {title, sub}` или `{file}`, `after: {…}`, `labels`, `at: [открытие]` |
| `quote` | цитата крупно | `text` (`*акцент*`), `author` |
| `word` | одно слово на весь экран без плашки | `text`, `fx`: `pop` / `shake` / `slam` / `stretch`, `size`, `color` |
| `hub` | центр и связи с сервисами, счётчик | `center`, `nodes: [[подпись]]`, `at`, `count` («1 500+ приложений»), `count_at`, `glow_at` |
| `form` | окно сайта, поля заполняются, кнопка нажимается | `url`, `title`, `fields: [[подпись, значение]]`, `at`, `button`, `press_at`, `checks`, `checks_at` |
| `site` | макет сайта: скан, фирменные цвета, шрифты | `brand`, `colors`, `fonts`, `scan_at`, `colors_at`, `fonts_at`, `done`, `done_at` |

Эмодзи-стикеры и эмодзи в графике ставь, только если человек сам их любит (см. правила в brand.md).

- **split** — отрезки `[a, b]`, когда экран делится: сверху панель, снизу человек.
- **shots** — что в панели сплита, по порядку.
  - Запись экрана: `rec` — имя файла без расширения (`rec1`).
    - `m` — пары `[секунда исходника, секунда записи]`. Между парами запись идёт линейно: можно ускорять, замедлять, делать стоп-кадр (две пары с одной секундой записи).
    - `crop` — пары `[секунда записи, Y]`: какой кусок высокой записи виден в окне. Окно ≈ 866 px записи по высоте при ширине 1170.
    - `blur` — `[с, по, x, y, w, h]` в секундах записи и пикселях записи.
    - `ff: 1` — значок перемотки ▶▶ и звук перемотки.
  - Картинка: `img` (путь в папке ролика), `src: [a, b]`, `label` (по умолчанию «РЕЗУЛЬТАТ»; `""` — без плашки). Высокая картинка плавно прокручивается.
  - **Моушн-панель**: `scene` и `src: [a, b]`. Её рисует сам шаблон, вживую и на странице, и в рендере, отдельного видео не нужно.
    - `title` — заголовок панели, `*№3*` красится акцентом; `tag` и `tag_at` — плашка справа; `foot` — мелкая подпись внизу;
    - `body` — 1–2 анимации из библиотеки, сверху вниз; у каждой можно задать `show_at` — когда она появляется;
    - `id` (`s1`, `s2`…), `label` и `alts` — как у карточек: варианты панели на выбор.
    Сплит с моушн-панелями ставь, когда записи экрана нет, а человек перечисляет, объясняет по шагам или называет цифры.
- **taps** — касание пальцем: `[секунда, запись, x, y]` в пикселях записи.
- **hl** — рамка с подписью: `[с, по, запись, [x, y, w, h], "ПОДПИСЬ"]`.
- **steps** — пилюля над окном: `[секунда, "ШАГ 1", "Текст"]`.
- **zoom** — `"auto"`: смена крупности на каждом стыке, 1.0 ↔ 1.07. `[]` — без зума. Список `[[a, b, 1.1]]` — свои отрезки.
- **fix** — как писать слово в субтитрах: `{"номер слова в words.json": "Текст"}`. Пустая строка убирает слово из субтитров.
- **accent** / **no_accent** — номера слов, которые выделить цветом или, наоборот, не выделять.
- **src_max** — последняя секунда исходника, которую можно показывать. Нужно, если в конце записи заставка CapCut и т. п.
- **layout** — раскладка только для этого ролика, стиль не трогает: `{"cards_top": 300, "caption_y": 1330}`. `cards_top` — откуда висят карточки (вместо `brand.cards.top`), `caption_y` — где субтитры (вместо `brand.captions.y`). Например, карточки наверху над головой, а субтитры между подбородком и низом кадра.

Координаты для `crop`, `blur`, `taps` и `hl` удобно брать с сетки: `python3 scripts/peek.py work/X rec1 2,7.5,12`.
